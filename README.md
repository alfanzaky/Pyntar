# Pyntar
Aplikasi Android modern yang memungkinkan siswa mengelola tugas akademik secara efisien, sekaligus menyajikan analitik pembelajaran yang bermakna dan wawasan produktivitas.

Development Implementation Plan

Platform: Android Native

Language: Kotlin

UI: Jetpack Compose

Architecture: Clean Architecture + MVVM

Database: Room (SQLite)

Minimum SDK: 24

Target SDK: 36

Status: Development Plan
